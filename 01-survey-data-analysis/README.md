# Data Analyst Survey Dashboard

> Project Type: Guided Learning Project  
> Based on Tutorial: Power BI Full Course / Project by Alex The Analyst (https://youtu.be/I0vQ_VLZTWg)

## Overview
This project was built following Alex The Analyst's tutorial to learn and practice end-to-end Power BI skills. As part of this hands-on project, I worked with survey data and practiced data cleaning, modeling, and dashboard creation.

## Key Skills & Features Practiced
- Power Query: Data cleaning and pre-processing in Excel & Power BI.
- DAX: Custom measures and calculated logic.
- Data Modeling & Structuring: Relationships and grouping data.
- Visualizations & Interactivity: Drill-down features, conditional formatting, and custom chart designs.
